# The Secret of Monkey Island

Комнаты и байткод «Последнего парома» лежат в [`last-ferry/`](last-ferry/). Демо использует оригинальные костюм Гайбраша, пристань Мêlée, звук и CHAR 1 с кириллицей WebSCUMM. Грузовой подъёмник соединяет зоны ходьбы на остановках и переносит актёров вместе с платформой.

Пересобрать графику можно командой `python TSoMI/last-ferry/draw.py <pixel-art-html-skill>/SKILLS/pixel-art-html TSoMI/last-ferry .local/ferry-art` с [проверенной ревизией Pixel Art HTML](https://github.com/gvastethecreator/pixel-art-html-skill/tree/5373810d5cacbbd50c14039ace9d70ebef84e794). Исходные сетки и превью сохраняются в `.local/ferry-art`.

[Играть](https://akulaflow.ru/webscummtest/) · [English README](README.md) · [WebSCUMM](../README.ru.md)

Здесь находятся настройки английской DOS CD-версии, веб-пакет, экспортёры, шрифты и тесты игры.

## Веб-пакет

Плеер загружает пакет `WSC1`, в котором хранятся декодированная индексированная графика, палитры, маски глубины, кадры костюмов, растровые шрифты, скрипты, последовательности AdLib и декодированные звуковые эффекты. JSON-каталог описывает двоичные блоки, файл сжимается gzip. Исходные архивы `.000` и `.001`, DOS-программа, драйверы и исходный образ CD остаются вне Git и сайта.

Чтобы пересобрать `TSoMI/assets/monkey1.wsc.gz` из локальной DOS CD-версии, запустите:

```powershell
npm run assets:monkey -- 'D:\MONKEY1'
```

## Музыка с CD

Веб-сборка включает 24 дорожки, перекодированные с диска `MNKY_TWN`. Браузер загружает каждую по мере надобности. В игре нумерация аудио начинается с 1, что соответствует физической дорожке 2. Титры и сцена с дозорным используют дорожку 17 с разными смещениями. Плеер учитывает позицию в кадрах CD и число повторов, заданные игрой.

Чтобы пересобрать дорожки с помощью FFmpeg, запустите `node TSoMI/tools/export-cd-audio.ts путь/к/MNKY_TWN.cue`. Стерео MP3 появятся в `TSoMI/assets/cd/`.

## Костюм Гайбраша

В Monkey Island у `COST 44` в chore `18`, `LEFT`, на слое `01` последовательность ног совпадает с архивным GIF. Чтобы собрать полный предпросмотр этой сцены, выберите `LEFT`, задайте chore `03` как **SET BASE POSE**, затем откройте `18`.

## CHAR 1 для перевода Monkey Island CD

Справка BYLE использует оригинальные 8-пиксельные глифы и ширины `CHAR 1` с DOS CD. Добавлены 66 букв русского алфавита, включая `Ё` и `ё`. Одинаковые по начертанию латинские и кириллические буквы используют исходные рисунки. [Строка команд MI1 CD](https://www.scummvm.org/data/screenshots/scumm/monkey/monkey_dos_en_1_4_full.png) · [Оригинальный атлас CHAR 1](https://github.com/dbonates/MI-CHARfontEditor/blob/cdbee321f330c7fe36615945477ffa3a43bc40f4/char0001.bmp)

```powershell
npm run font:char1 -- 'D:\MONKEY1'
```

Команда сохраняет готовый блок SCUMM v5 `CHAR` в `.local/char1-ru/CHAR_0001`. Вторым аргументом можно задать другой выходной файл. Блок рассчитан на замену ресурса `CHAR_0001` при перепаковке копии игры. Исходные `.000` и `.001` открываются для чтения. [Формат CHAR](https://www.scummvm.org/old/docs/specs/char.php) · [Работа с CHAR в ScummTR](https://github.com/dwatteau/scummtr/blob/main/FAQ.md#where-are-the-fonts-stored)

Для текста перевода используйте CP866. Функция `encodeChar1RussianText` в `fonts/char1-russian.ts` переводит обычный текст с русскими буквами в нужные байты. Кодирование команд SCUMM остаётся задачей упаковщика строк. Русские буквы занимают `80–AF`, `E0–F1` (hex), включая часть западноевропейских позиций. Остальные слоты, в том числе ASCII, сохраняют исходные глифы. `CHAR 1` покрывает строку команд и меню сохранения. Для полной локализации отдельно понадобятся другие наборы `CHAR` и перевод самих строк. [Служебные коды SCUMM](https://github.com/dwatteau/scummtr/blob/main/FAQ.md#what-are-all-these-weird-123456789-symbols)

## Совместимость

Проверены титры, сцена с дозорным, причал, вход в SCUMM Bar и начало разговора с заключённым. Из iMUSE реализованы очередь команд SCUMM v5, состояние воспроизведения, громкость и затухание. Адаптивные переходы iMUSE и сохранения ещё предстоит реализовать. Поддержка байткода неполная. Если скрипт обращается к неизвестной команде, плеер показывает номер скрипта и смещение.
