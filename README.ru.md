# WebSCUMM

[**Последний паром**](https://akulaflow.ru/webscummtest/#ferry) — короткая фанатская предыстория о том, как Гайбраш попал на Мêlée. Для запуска выберите **LAST FERRY DEMO** и **PLAY**. Новые комнаты, костюмы и загадки работают в том же проигрывателе SCUMM, что и оригинальная игра.

[Играть](https://akulaflow.ru/webscummtest/) · [BYLE](https://akulaflow.ru/webscummtest/#byle) · [Просмотрщик комнат](https://akulaflow.ru/webscummtest/#rooms) · [English README](README.md)

TypeScript-движок и браузерные инструменты для SCUMM. Игровой режим пока запускает английскую DOS CD-версию **The Secret of Monkey Island**. Интерфейс собран на Vue и Vite, как в [WebKyra](https://github.com/yanakulov/WebKyra).

## Как играть

Откройте [игру](https://akulaflow.ru/webscummtest/) и нажмите **PLAY**. В веб-пакет уже входят эффекты AdLib и музыка с DOS CD. Через **OPEN LOCAL CD DATA** можно до запуска выбрать свою пару файлов `.000` и `.001`. **MENU** или **F10** возвращают в стартовое меню.

**LOAD CD TRACKS** принимает дорожки с именами вроде `track01.mp3` (также WAV, Ogg, Opus, FLAC и M4A, если их читает браузер) или пару `.cue` и `.bin` с аудиодорожками. Для MIDI-замены вроде `track17.mid` выберите банк General MIDI `.sf2` через **LOAD SOUNDFONT**. Браузер читает локальные файлы напрямую.

Щелчок по сцене задаёт направление ходьбы, щелчок по панели выбирает команду. **Esc** пропускает ролик, точка переводит диалог к следующей реплике.

На телефоне ведите пальцем по экрану, чтобы сдвинуть курсор. Тап выполняет действие в точке, где стоит курсор. Во время заставки тап пропускает ролик, а во время реплики переводит диалог дальше.

[Ресурсы и совместимость Monkey Island](TSoMI/README.ru.md)

## Локальный запуск

Нужен Node.js 24.

```powershell
npm ci
npm run dev
```

Откройте [игровой режим](http://127.0.0.1:5174/).

[BYLE](http://127.0.0.1:5174/#byle) работает и без архива. При первом открытии появится справка, её также можно вызвать по **F1**. **FILE → ROOM VIEWER** открывает [просмотрщик комнат](http://127.0.0.1:5174/#rooms).

## Как собрать анимацию

Нажмите **ОТКРЫТЬ ПРИМЕР** в справке. В `BOUNCE` слева виден один рисунок, справа проигрывается последовательность `00 01 02 01`. **STOP** останавливает её, **STEP** показывает следующий кадр. Нижняя строка **LIST** подсвечивает текущий кадр.

1. Выберите **FILE → NEW COSTUME**. Выберите цвет справа и нарисуйте первый кадр на левом поле. Правая кнопка стирает.
2. Нажмите **CEL** под **START** и **STEP**. Кадр появится в **LIST**.
3. Выберите `01` в верхней строке **CEL**, нарисуйте второй кадр и добавьте его в **LIST**. Нажмите **START**.

**LIMB** выбирает слой, например тело или голову. **CHORE** выбирает действие, например ходьбу. Для каждой пары действия и направления есть свой список кадров на каждом слое. Shift-клик по ячейке **LIST** заменяет кадр, правый клик удаляет. **XREL** и **YREL** смещают следующие слои. Shift-клик уменьшает значение. **CHORES** управляет циклом и базовой позой предпросмотра.

**FILE → SAVE COSTUME** сохраняет редактируемый `.byle.json` с палитрой. **FILE → MAKE COSTUME** собирает бинарный ресурс `COST` версии 5 (`.cost`), а **LOAD COSTUME** открывает оба формата. `COST` хранит индексы цветов, которые интерпретируются палитрой комнаты. Отдельно открытый `COST` отображается с запасной палитрой EGA и серыми цветами для остальных индексов. Исторический исходник `.byl` пока не читается.

## Локальные архивы для редакторов

В BYLE и просмотрщике комнат можно открывать совместимые архивы PC SCUMM v5. Выберите пару `.000` и `.001` с одинаковым именем. В BYLE команда **FILE → OPEN SCUMM DATA** загружает список `COST` и сохраняет открытый проект до выбора костюма.

**PAINT PNG** в просмотрщике комнат открывает [редактор фонов](https://akulaflow.ru/webscummtest/#paint). Он принимает непрозрачные PNG до 256 цветов и сохраняет правки в индексированный PNG исходного размера.

Чтобы добавить локальный архив в диалог выбора файлов в режиме разработки, укажите каталог игры. Если в нём несколько пар, задайте имя через `WEBSCUMM_GAME_STEM`.

```powershell
$env:WEBSCUMM_GAME_DIR = 'D:\MONKEY1'
npm run dev
```

Проверены два разных набора ресурсов: Monkey Island PC CD (83 комнаты, 119 костюмов) и DOS-демо Indiana Jones and the Fate of Atlantis (11 комнат, 20 костюмов). [Каталог демо ScummVM](https://www.scummvm.org/demos/)

## Состояние движка

После загрузки архива движок исполняет глобальный скрипт 1. Глобальные и локальные скрипты выполняются до команды ожидания или завершения, а при смене комнаты запускаются её обработчики выхода и входа. Персонажи двигаются по областям `BOXD` и маршрутам `BOXM`. Рисование использует игровые `SMAP`, `COST`, маски глубины и растровые `CHAR`. Щелчки по экрану и панели обрабатывают игровые скрипты. [Руководство SCUMM](https://tandell.com/misc/SCUMM-Tutorial-0.1.pdf) · [Байткод SCUMM v5](https://www.scummvm.org/old/docs/specs/scrp-v5.php)

Рендерер костюмов использует исходные пороги масштабирования строк и столбцов и ведёт анимацию каждой части тела отдельно. Камера начинает следовать за персонажем после пересечения порога и прокручивает экран полосами по восемь пикселей.

```powershell
npm test
npm run build
```

Тесты проверяют экспорт и повторный импорт `COST`, запуск из веб-пакета, вступление, плакат на причале, вход в SCUMM Bar и диалог в тюрьме. С `WEBSCUMM_GAME_DIR`, указывающим на Monkey Island PC CD, они также проверяют исходный архив и сравнивают кадр титульного экрана из двух источников.
